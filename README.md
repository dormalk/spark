# SPARK — MVP זוגי

אפליקציית PWA בעברית ובכיווניות RTL, בעיצוב שחור/בורדו/זהב.

## מה כלול
- ארבע חפיסות: קרבה וחיבור, ניצוץ ותשוקה, אזור נועז, הפתעה ובונוס.
- שליפת קלף, סימון כהושלם או דילוג, והיסטוריה.
- יצירת קוד זוגי והצטרפות עם קוד.
- התקנה כאפליקציה (PWA) ושמירה מקומית.
- חיבור Supabase עם פרטי הפרויקט שהוגדרו ב-app.js.

## הפעלה
1. פתחו את Supabase project.
2. היכנסו ל-SQL Editor, צרו New query, הדביקו את כל `supabase.sql` והריצו.
3. העלו את התיקייה לשרת סטטי התומך HTTPS, למשל Cloudflare Pages או Netlify.
4. פתחו את כתובת האתר בטלפון והוסיפו למסך הבית.

אפשר לבדוק מקומית באמצעות שרת פיתוח סטטי (לא לפתוח את index.html ישירות כקובץ), למשל:
`python -m http.server 8000`

## חיבור וסנכרון — הערה חשובה
ה-URL והמפתח הציבורי הוזנו ב-app.js. המפתח מסוג publishable/anon מיועד לשימוש בדפדפן; לעולם אין להכניס לכאן service_role או secret key.

**הגרסה הזו היא אבטיפוס.** קוד זוגי משמש כרגע גם כאמצעי גישה למרחב, ופונקציות ה-RPC מאפשרות למי שיודע את הקוד לקרוא את מצב הזוג ולמי שיודע מזהה פנימי לשמור מצב. לפני השקה ציבורית יש להוסיף אימות משתמשים, חברות זוגית מאומתת, הגבלת קצב, הרשאות קשיחות ופתרון להתנגשויות עדכון. אין לשמור מידע רגיש באבטיפוס.

## מגבלות MVP
- נתוני ההיסטוריה מסתנכרנים רק לאחר סימון קלף כהושלם/דילוג.
- אין עדיין סנכרון בזמן אמת או טיפול מלא בעריכות בו-זמניות.
- במצב מקומי ללא הגדרת Supabase, המידע נשמר רק באותו מכשיר/דפדפן.
- תוכן הקלפים הוא דוגמאות ראשוניות וניתן להרחבה.

כל משימה היא הצעה בלבד: שני בני הזוג יכולים לדלג, לעצור או לבחור משהו אחר בכל שלב.
